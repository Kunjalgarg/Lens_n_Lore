# 📸 Lens & Lore — Where Photography Meets Storytelling

**Lens & Lore** is an interactive photography portfolio platform designed to present visual stories in a smooth and cinematic browsing experience.

Built with **React, Tailwind CSS, and FastAPI**, this project combines modern frontend design with a lightweight backend to manage user interactions, download requests, and form submissions.

This project was also my **first experiment with backend development using Python and FastAPI**, exploring how frontend applications can interact with a server and database.

---

# 🌟 Highlights

✨ A visually immersive photography portfolio  
🔐 Custom download control logic for images  
⚡ Smooth carousel navigation with keyboard controls  
🗂 Structured photo galleries with sub-photo collections  
🧠 Backend experimentation with FastAPI and Python  

---

# 🚀 Features

## 🖼️ Interactive Photo Galleries
- Main gallery with **multiple photo collections**
- Each collection contains **sub-photos grouped under a story**
- Smooth **carousel viewer** for browsing images

---

## ⌨️ Keyboard Navigation

Navigate photos using keyboard shortcuts:

- **→ Right Arrow** → Next photo  
- **← Left Arrow** → Previous photo  

This creates a **seamless browsing experience similar to professional photography platforms**.

---

## 🔒 Image Protection Logic

To protect photography work:

- **Right-click download disabled**
- Custom **user-specific download request system**
- Prevents casual image scraping

This demonstrates **client-side logic combined with backend request handling**.

---

## 📥 Photo Download Request System

Users can request high-quality image downloads via a form.

The system:

- Captures user request data
- Stores it in a backend database
- Allows the photographer to review download requests

---

## 📝 Contact Form with Backend Storage

A working **contact form** connected to the backend.

Features:

- Form submission validation
- Backend API integration
- Data stored in a database

This was built as a **first exploration into full-stack communication using FastAPI**.
