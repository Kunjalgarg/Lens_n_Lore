# 📸 Lens & Lore — A Storytelling Photography Portfolio

**Lens & Lore** is a visually rich, interactive photography portfolio built with **React**, **Tailwind CSS**, and **FastAPI**. It brings your captured stories to life with animated image sliders, a smooth contact form experience, and a secure download request system backed by MySQL.

---

## 🚀 Features

- 🎞️ Main + sub-image portfolio gallery with hover effects
- 🖼️ Zoomable modal view with image preview
- ✉️ Contact form with backend storage
- 🔒 Download permission system with email approval
- 🗃️ Saves all submissions as `.txt` logs + MySQL database
- 💡 Fully responsive design and smooth dark theme

---

## 🧰 Tech Stack 

| Frontend               | Backend                | Database       |
|------------------------|------------------------|----------------|
| React + Vite           | FastAPI (Python)       | MySQL          |
| Tailwind CSS           | Uvicorn (ASGI server)  | dotenv-based config |
| Framer Motion          | CORS Middleware        | `.env` secured |
